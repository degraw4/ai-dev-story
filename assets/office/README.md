# 办公室场景素材

2026-10-19 至 2026-10-20 使用内置 imagegen 生成三张 PNG。客户端由 [office.js](../../src/office.js) 按真实员工、工位、算力和项目状态组合绘制；方案过场复用员工图集。未调用外部图像 API，也未使用图像处理脚本生成或编辑素材。

| 文件 | 图像规格 | 用途 | 提示词 |
| --- | --- | --- | --- |
| [office-background-v2.png](office-background-v2.png) | 1536 × 1024，实色背景 | 四工位创业办公室，固定老板桌与秘书桌，中央工位动态绘制 | [创作要求记录](starter-prompt.txt) |
| [office-sprites-v2.png](office-sprites-v2.png) | 1536 × 1024，带透明通道 | 四列三行图集，角色与家具组合 | [原始生成提示词](sprites-prompt.txt) |
| [office-expanded-v2.png](office-expanded-v2.png) | 1536 × 1024，实色背景 | 扩张后的城市总部，独立建筑、窗户、入口和布局 | [原始生成提示词](headquarters-prompt.txt) |

创业办公室参考用户提供的 docs/design/2.png 观察像素密度、等距视角、家具细节与街区氛围；图集和总部以本项目生成的创业办公室为视觉参考。原始商业游戏截图及 design.mp4、dev.mp4 仅作本地参考，已加入忽略列表，不作为网页素材或 Git 分发内容。视频用于观察设计点数和研发点数的显示节奏。创业办公室提示词文件是创作要求的整理记录，不能作为逐字原始请求；另两份为实际调用中保存的提示词。

图集从左到右、从上到下编号 0 至 11：索引 0 至 7 为不同员工的完整工作站，索引 8 为空工位，索引 9 为老板，索引 10 为秘书，索引 11 为搬家纸箱。老板和秘书通过背景桌面遮挡组合成坐姿。员工增减由经营状态决定，固定背景不烘焙员工人数。

画布保持素材等距视角，以覆盖方式填满中间区域，允许裁去周边街区；透明图集以最近邻方式缩放。研发数字和能力提升提示从实际通知生成，动画不修改经营状态。
