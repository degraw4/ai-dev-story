# 创意收件箱

用户提供原始创意，助手负责整合。先记录来源，再判断如何进入游戏。尚未采纳的创意不增加当前版本的开发范围。

历史条目保留当时提案；最新的公司名称与负责人招聘边界见 IDEA-011，当前内容统一以 DEMO_CONTENT.md 为准。

新增人才创意见 IDEA-012。尚未采纳的员工不会因为出现在收件箱中而自动进入当前招聘名单。

## 状态

待整理：保留输入，尚未形成游戏表达。
提案：已说明玩法或表现，待决定。
已采纳：已进入当前设计并链接到相关任务。
暂存：保留灵感，不进入当前版本。

## 创意记录格式

- 编号与日期。
- 来源：用户原话或助手提案，分别标注。
- 原始创意。
- 讽刺的具体现象。
- 游戏表达：剧情、规则、画面、对白或声音。
- 玩家操作与经营后果；纯环境表达注明不改变数值。
- 适合出现的章节。
- 需要的资源、实现成本与名称识别风险。
- 状态、设计位置与 TODO 编号。
