# 名称、素材与发布检查

本文件管理项目的命名、素材来源和使用权限，不是对尚未完成作品的法律结论。检查范围包含代码、图像、字体、音乐、音效、角色和宣传内容。

## 创作方式

- 联想到行业共性：发布命名、榜单细分、资本叙事、参数竞赛和用户反馈。
- 公司、模型、榜单和人物采用原创设定；可以混合多个现实现象形成虚构角色。
- 角色造型、标志、配色、名称和台词一起检查，避免只改一字却仍构成明显的一对一仿冒。
- 《游戏发展国》用于研究经营节奏、像素办公室表现和音乐气质；项目另行创作图像、角色、界面素材、旋律和录音。
- 虚构行为不作为真实公司或个人行为的事实描述。用户提出具体影射创意时，单独检查最终表达。

商标识别与混淆需要结合标志和使用情境判断，改名本身不能完成这项判断。[国家知识产权局《商标侵权判断标准》发布页](https://www.cnipa.gov.cn/art/2020/6/15/art_3611_204507.html?xxgkhide=1)

可识别的人物形象与名誉涉及独立的权利边界；像素化也不能直接视为已获授权。[《民法典》人格权编](https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478416.shtml)

## 素材登记

每项实际引入的素材登记以下信息：

| 字段 | 内容 |
| --- | --- |
| 素材编号与路径 | 发布包中的文件和可编辑源文件位置 |
| 用途 | 使用场景及是否进入公开网页、截图或宣传 |
| 来源与作者 | 原创作者、委托作者或外部来源地址 |
| 获取时间与版本 | 能定位实际采用的素材 |
| 权限依据 | 许可证文本、授权记录或适用的工具条款 |
| 允许的用途 | 源码仓库分发、网页展示、修改、商业使用的适用范围 |
| 署名要求 | 需要保留的名称、链接和声明 |
| 修改与生成记录 | 改动说明；生成素材记录使用工具与来源条件 |
| 核查状态 | 待核查、可使用、需替换 |

## 代码与素材许可

项目代码和项目原创素材采用 [MIT 许可证](../LICENSE)，包括本项目生成的图片、音乐与音效。第三方作品、名称及商标不因此获得再许可；第三方依赖适用各自的许可。

音乐需同时考虑作曲、录音和采样来源；字体需核对网页嵌入与再分发条件。优先使用原创合成音色与旋律，保留音符数据或生成代码。

具有公开下载地址不等于允许重新分发。合理引用存在适用条件，不能把“讽刺作品”当作通用授权。[国家版权局《著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)

GitHub 上公开可见的仓库仍需明确许可证才能表达开源使用权限。[GitHub 许可证说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)

## 发布前核对

逐项核对实际发布包与登记内容；处理待核查素材；补齐许可证与署名；检索最终游戏名与主要虚构名称；检查容易混淆的标志、人物形象和事实性表述。

虚构声明用于说明作品性质，不能替代授权和具体内容核查。必要时对保留的明显影射或争议素材取得专业意见。公开地域与分发方式确定后，还需核对相应发布条件。

记录结果与证据，不能仅写“合规通过”而没有检查对象和范围。
