# 《AI发展国》Demo 设计入口

状态：可玩原型采用办公室主屏、秘书引导、三类能力和分期招聘，使用真实经营规则、独立发布页面、十段交互剧情、存档和事件音效。玩家发布频率优化、真人完整试玩和线上发布仍有后续工作。

## 1. 核心经营体验

玩家在美国经营一家虚构 AI 公司，以榜分、发布与宣传证明成功。模型实际使用效果通过用户反馈形成讽刺，不成为主要胜负条件。

每次为新模型选择名称、主攻方向和方案负责人；负责人先花游戏时间设计方案，交付后全员自动完成四阶段研发。完成时主动弹出发布筹备，玩家决定是否付费报道，主持由系统安排。正式发布切换到独立页面，揭幕型号、展示三项成绩与真实战报，然后展示媒体报道与用户反馈。正式成绩带来排名、融资与订阅，公司再招聘、采购和开始下一款。立项先支付整款训练预算，发布、招聘和设备另有支出；媒体可以换取两个账期的付费订阅加成。

同一时间只有一个项目，多名员工协作。已完成项目等待发布，发布后释放位置并增加公司积累。员工三项能力随实际工作积累经验，影响方案和属性贡献；算力影响推进速度。点数动画展示真实贡献，历史模型保持各自成绩。

每位参与研发的员工都按自己的三项能力提高模型分数。人数增加能增强团队总贡献，同样人数时专长与成长决定对应方向的提升；研发页显示参与人数和能力合计。负责人决定初始方案，全体参与者共同决定最终成绩。

立项选人使用员工单选卡片，每张同时展示编程、办公、多模态的当前能力。主攻方向高亮，选择与切换方向不会改变原始能力数字。忙于额度重置的 Rebo 保留数值展示，但不能选择；负责人离职后重选也采用同一形式，并保留已经消耗的设计时间。

## 2. 已确定的产品边界

| 方面 | 当前规则方向 |
| --- | --- |
| 时间 | 自动推进，可以随时暂停；后台与读档没有离线追赶 |
| 主界面 | 办公室占据主要空间，整页不滚动；研发、团队、人才、榜单、资金、新闻和反馈从按钮进入二级窗口 |
| 新手引导 | 公司秘书小满先介绍界面，再按实际项目和发布进度说明下一步，可以跳过、重看并随时求助 |
| 团队 | 两人起步，逐步扩大到约六至八人；当前实施上限取八人 |
| 招聘 | 候选按首次发布与游戏日开放；招聘仍需满足现金、工位和在岗限制 |
| 换人 | 主动辞退需赔偿，离职员工留下一句狠话 |
| 研发 | 按项目立项、研发与发布，公司积累保留，同一时间只开发一款 |
| 能力 | 编程、办公、多模态，共用研发流程 |
| 榜单 | 三张专项榜与综合榜；排名按真实已发布模型计算 |
| 剧情 | 按游戏时间进入阶段，竞品发布与关键新闻推动故事；经营表现决定对白 |
| 结局 | 榜单常青树、融资永动机、明年一定第一、发布会照常 |

三类能力开局可选，每款只设一个主攻方向。综合分为同一款模型的三项分数之和，不能拼接不同型号的最高单项成绩。比分、任务和收支使用确定规则，不调用真实模型。

## 3. 公司成长与行业环境

六名特殊候选为 Alex Weng、Rebo、卡帕题、Boris Cherry、Tim Detmer、Max Score；普通员工用履历、专长与合同区分，国籍和肤色不决定能力或诚信。工位和设备分别采购，工资与运行费持续产生。

Morgan Byte 与 Casey Deck 开局开放；首次正式发布后开放 Alex Weng 与 Max Score；第 21 日开放 Rebo 与 Tim Detmer；第 42 日开放卡帕题与 Boris Cherry。界面显示尚未开放的条件，不能提前付费招聘。开放日期属于可调整的原型节奏，规则依据见 ECONOMY。

等距像素办公室铺满中间画面，主屏保留现金、综合名次、算力、活跃用户、评价、游戏日和时钟按钮。扩张时迁入不同布局的城市总部。管理窗口内可以滚动，返回办公室始终可见；阅读和切至后台暂时暂停，返回后自动继续，玩家主动暂停仍保留。老板代表玩家，小满是唯一秘书，在办公室各有固定位置，周围可见街道与邻里环境。小满先介绍身份、四项指标、时间控制和管理入口，再带玩家选方案负责人、立项、观察自动开发和发布，随后说明到账时间与扩张选择；查看过资金页后进入下一款模型的建议。对话不替玩家经营、不赠送资源。

未发布产品时，客户评价显示“暂无评价”，正式首发后才展示评分。排行榜每条模型提供介绍，鼠标悬停、键盘聚焦或点击即可查看；介绍使用该条模型的发布日期、主要方向与独立文案，不把后续版本的新闻归到当前模型。

机器之薪、量子味、新智猿共用一次报道机制，费用和收益由 ECONOMY 计算；报道提高未来两个账期的付费人数与订阅收入，效果有期限，重复投放不叠加。报道主动弹窗，包含因型号和发布次数变化的标题与节选，分别使用技术包装、轻巧比喻和夸张震惊体。用户反馈主动展示评分、活跃用户、付费人数与订阅收入变化；Rebo 可以支付资源改善评价，评价权重保持最低。辞退员工主动弹出专属狠话和已支付赔偿。

五家模型竞品各最多四款型号，包含开局已有的一款，经营期间各发布三款，交错覆盖前中后段。CloseAI 与 AntiThropic 三次前后脚发布，前者突出办公，后者编程最强；Gloglo 以多模态为主要识别点，是千人以上的大公司，Jeff Damn 离职后仍有上千名员工。Meeta 和 DeepPeek 形成其他竞争与新闻。竞品不临时追着玩家改分，玩家可以超过它们。

Nvidya 由 Jenson Huang 负责，供应算力设备。Dario Amodie 和 Mark Zuckerbug 分别负责 AntiThropic、Meeta。公司负责人和 Jeff Damn 等新闻人物不进入招聘池。

CodeY 与 Cloud Code 是工具，各安排一次产品发布，不区分版本，其公告与模型成绩分别记录。DeepPeek 在中前期以 R1 和成本资料引发行业反应，只发布模型、技术与价格资料，不回应蒸馏指控。人才、股价、开放策略、竞品融资和上市准备只作新闻，不增加玩家的股票交易、竞品管理或真实身份检测。

## 4. 时间与内容基线

新公司采用 112 个整数游戏日、基础每日20秒的一倍时钟、五章和每七日账单；提供倍速。点数密集时会等当前逐点反馈显示完再结算下一日，保证图标可读。项目完成时打开筹备窗口，关闭后按进入前的运行状态继续，模型仍待正式发布。新公司继承为 11%，员工每 120 经验提升一点、单项最多成长六点；中后期竞品成绩逐步加强。具体参数属于可调原型基线。完整目标约 1—2 小时，真实时长由试玩测量。

全部 15 次竞品更新由确定表驱动，新闻池有 25 类内容，十五个剧情条目定义可复用的触发边界。五章正文将行业现场、办公室反应与经营选择串联，前段埋下的发布稿、账单与用户问题在后段和结局呼应。客户端从 26 个文稿片段中精选十段，在第 5、16、29、40、52、63、74、85、93、107 日触发，使用短对话、选词和资料翻看，承接对应原新闻。玩家可以跳过并回看，标题选词在末章回扣；其余十六段保留为可选素材，是否增加取决于试玩。

片段中的经营数据读取当前公司，回看时明确当前经营日。行业型号仅取片段日期之前的已发布记录。选择和翻页不修改经营结果；“查看当前资金”等按钮打开既有管理页。原本运行的经营在阅读结束后自动接续，主动暂停保持。既有公司首次启用时从下一游戏日起接续后续片段。

竞品模型到时入榜，新闻提供查看独立成绩页的入口；DeepPeek 保持安静的模型资料形式，不安排主持或回应争议。发布、研发完成、排名、融资、招聘、辞退、采购等使用不同原创音效，背景音乐与音效分别调节音量。标志使用 AI 青蓝、DEV 橙黄、STORY 绿色及明确词间距，保持像素经营游戏的明快表现。

新公司最后可发布日为 111，第 112 日完成最终结算。末章提前展示截止提醒和项目预计完成日；未发布成绩不补算进结局。提前破产优先进入尾声，不播放尚未发生的后续章节。v3 和 v4 存续公司接续 168 日日历及其原始经济参数，存档迁移保留实际进度。

## 6. 首个可玩原型与后续阶段

首个原型已形成首次发布、扩张与行业、恢复与结局三个操作环节。玩家能立项、选择方案负责人、暂停或倍速推进、发布打榜、获得收入、招人和采购；经营在浏览器本地保存，恢复时暂停。客户端检查范围见[可玩原型验证](../reviews/2026-10-19-playable-prototype.md)。

通过 npm start 进入[可玩原型](../../index.html)。[设计样张](../../design-preview/index.html)保留固定示例展示。当前试玩重点观察 112 日节奏、中后期竞品反超、员工成长、办公室搬迁和主动反馈；同时检查到账时点、发布频率、弹窗密度、新闻笑点和长期听感。[验证记录](../reviews/2026-10-20-office-pacing-feedback.md)分别记录代码检查、浏览器检查和未验证范围。

当前没有 1—2 小时真人体验证据，高效策略仍有重复发布风险，不能因为竞品各四款就认定玩家重复问题已解决。公开源码与在线网页已发布，线上完整流程仍需验证。任务状态以 [TODO.md](../../TODO.md) 为准，素材边界见 [ASSET_RIGHTS.md](../ASSET_RIGHTS.md)。
