# 历史两方向方案的数值核算与结局可达过程

本文件仅对应[算术与文字两方向的历史规则](../reviews/2026-10-19-two-direction-economy.md)。下列 73 行经营记录、四结局结果、员工收益和发布时间对照均为该规则的证据，不能证明当前候选能力方案的排名、收支或结局可达性。当前规则草案见 [ECONOMY.md](ECONOMY.md)。

运行 [check-design-balance.mjs](../../scripts/check-design-balance.mjs)：

```bash
node scripts/check-design-balance.mjs
```

历史核查使用 Node.js v22.16.0，退出码 0，所有断言完成。脚本包含六名特殊员工、五家对手、报价新闻、订阅新闻、额度重置、付费媒体与四种结局。再次运行只能复算上述历史规则，不是当前能力方案的验证，也不是正式游戏引擎。

## 7. 特性与边界证据

- Wang 文字专项训练贡献4，费用1，占算力1；由他筹备时报道费用3，其他人筹备时费用6。
- 卡帕题算术专项训练贡献7，费用1，占算力1。
- Boris 文字专项训练贡献9，费用3，占算力1，增益与费用同时发生。
- Tim 算术专项训练贡献5，费用1，占算力0；双机冲刺贡献8、费用3、占算力1。
- Max 算术整理贡献5、费用0、占算力0；专项训练仍为普通的5分，不能把加成扩展到所有研发。
- Rebo 第二周加入并重置，评价21变26，多花4；同样招聘但休息的对照保留21。两条完整经营的积分和排名一致，现金相差4，均为明年一定第一。重置可能通过现金间接影响结局，不能声称所有情况下结局永远不变。
- 连续重置把评价上限限制为50，满分后不允许再次重置收费。
- 首周弱发布报道费6、收入3；积累后第二周强发布报道费6、收入10。同一发布的预热和复盘形式得到相同结算；没有本周发布不能补买报道。
- 新闻报价在第4、5周为9，第12周为16，第20、21周为10；第8周订阅增加4，第16周减少4。效果只按相应周生效。
- 首周招卡帕题与Rebo、买两单位算力；Avery 专项训练，其余三人整理本职题，现金恰好0，仍可经营。
- 首周招卡帕题与Boris、买两单位算力，三名研发人员各训练本职、Jules 发布；一次性64后只余6，但融资190与订阅23足以支付固定16，周末现金203。
- 完全不操作在第12周破产。
- 同分比较覆盖历史模型先发与同周玩家先发；榜单名次始终为1至6或未参榜。
- 无新积分发布、同时安排同一员工研发与发布、招聘公司老板、首次发布前重置、预支收入支付一次性费用，均拒绝。
- 四结局的负现金优先、冠军优先、现金260阈值均有断言；融资总额最多190。

## 8. 未验证范围

尚未实现正式游戏、存档或网页端经营流程，没有真实玩家试玩。每个员工的长期吸引力、后期重复操作、报道是否经常成为固定选择、24周的实际耗时与客户评价的趣味，都需要原型验证。不能把这些算例称为已经完成整体平衡。
