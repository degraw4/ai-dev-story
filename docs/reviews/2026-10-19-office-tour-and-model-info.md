# 界面导览、模型介绍与自动研发验证

日期：2026-10-19，Asia/Shanghai。开发基线 13f6f5d。最终代码、截图、设计和本记录由同一提交定位。范围包括用户本轮五项试玩反馈，以及随后确认的员工方案、自动四阶段、算力速度和四张参考截图，来源见 DEC-042、DEC-043。

## 本地结果

- 五步办公室导览先介绍小满、点点、老板、四指标、时间和七个入口，然后才进入立项。导览可退回、跳过、刷新恢复与重看，画面对应区域突出显示。
- 未发布产品时，首页和无产品结局显示“暂无评价”；正式首发后才显示当前客户分数。
- 小满是秘书，老板是玩家，点点是电脑里的账本助手。办公室有老板和秘书位置、街道、邻居建筑、咖啡店、树木花坛及车辆；员工工位仍读取实际名单。
- 二十个竞品型号各有介绍，玩家型号按实际主攻、成绩和媒体生成说明；支持悬停、焦点、点击和 Escape，浮层位于视口内。
- 立项选择员工出方案，设计耗费两游戏日；过场显示负责人工作、真实进度及三项方案成绩。之后全员自动经历数据处理、预训练、后训练、评测，无逐员派工。
- 算力实际占用并影响推进速度；同一团队完成相同工作量的最终三属性不因加速减少。主屏开发条显示阶段、进度、属性与真实当日新增量。
- 原创发布舞台增加主持人、展示屏与观众；首次融资和首次综合登顶有去重事件卡。演出不重复结算资源。
- v3 自动研发独立保存；v2 手动研发与 v1 五方向旧档保留，欢迎页可选导出，明确开张后创建新规则公司。

用户提供的四张商业游戏截图只作本地构图与交互参考；未修改原图，未加入网页资源或 Git 分发。场景由 src/office.js、src/stage-art.js 原创代码绘制。

## 状态与兼容检查

- 员工负责人缺失、非法方向、单项目冲突、未开放招聘、超容量采购被拒绝且不修改原状态。
- 方案负责人离职保留设计时间，明确重选后使用实际交付者能力；完成后的方案不撤销。新员工次日参与，辞退保留成果。
- Rebo 重置占用当日，完成后下一日自动归队；没有员工时不产生研发进度。
- 每个中途游戏日保存后恢复，后续合法动作的经济结果与连续运行一致；暂停恢复不追赶离线时间。
- acceptedActions 使用唯一规则重放校验完整经济状态；伪造现金、分数、方案、阶段、余数、招聘、融资和通知均被拒绝。坏 JSON、重复观测、过大存档与不支持的动作也有检查。
- 原始 v1 和 v2 夹具分别来自 e41178c、13f6f5d。浏览器实际下载两个 JSON，字节与原文一致；新局、坏档处理后旧键仍原样保留。
- 浏览器保存配额失败、外部变更通知和通知前 pagehide 写入保护继续覆盖。坏档取消不会覆盖原文，显式确认才开始新局。
- 首次融资与首次登顶均从真实发布触发事件卡；发布回看不再展示已观察成就，也不再次入账。

用户指出的初始评分在浏览器中先复现失败：实际“2.1 / 5”，预期“暂无评价”；随后用同一断言验证修复。自动研发行为测试由实现代理先建立；存档重放和最终集成由主代理接续，不能把全部用例都宣称为完整测试先行过程。整合中修复旧档控件与脚本不一致，以及方案成果文字对比度；测试刷新等待改为确认新文档已加载，避免检查旧文档。

## 验证边界与阶段

浏览器只在独立测试页面注入 80 倍单调时钟；四结局、日期开放与额外开发状态由合法核心动作生成。常规表单多使用程序点击，新导览与模型介绍增加真实指针和模拟触摸；未声称完成所有实际手机设备、浏览器或无障碍组合。浏览器媒体播放状态已检查，远端测试机器没有提供真人听感证据。

并行代理在后半程触及使用额度，主代理接手完成核心存档、页面、插画、文档与最终验证。本轮有主代理自检与自动检查，但新增自动研发未完成另一位代理的最终独立审查；不沿用上一版本的独立审查结论。

I-05、I-06 完成本地功能与自动验证，继续 T-01 真人试玩。完整时长、长局重复感、长期听感、二十六段完整剧情演出、公开许可、GitHub 归属与公网部署仍有后续工作。本轮没有远端推送或公开发布。
