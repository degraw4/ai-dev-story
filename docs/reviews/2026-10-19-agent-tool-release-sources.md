## 创作边界

CodeY 和 Cloud Code 是游戏中的工具名称。现实产品史中，工具、承载它的模型以及工具的不同运行形态属于不同对象；游戏同样分别记录工具新闻与模型成绩。

游戏采用上述首发先后关系，结合模型能力发展安排工具出场；具体映射到哪一章、哪个游戏时点与停留时长待整体排期。现实日历可压缩，模型型号示例不强行充当精确历史年表。

双雄抢发、媒体标题和人物对白是虚构演出；时间接近的历史发布本身不证明现实公司故意抢发。只以工具新闻推进剧情，不因此新增玩家工具研发或工具评分系统。
